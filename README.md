# Card Duel TMA (Telegram Mini App)

Карточная пошаговая дуэль, оптимизированная для запуска внутри **Telegram Mini App** (на базе HTML5 Canvas и Telegram WebApp SDK).

Проект разработан совместно:
* Движок правил и базовый ИИ: **Вася (Endervasya12 / Huiotca22)**
* Canvas UI рендерер, система спецэффектов, Web Audio звук и TMA интеграция: **Dari-tyan**

---

## Архитектура проекта

```
card-duel-tma/
├── index.html          # Точка входа TMA (Telegram SDK, мобильный контейнер, HUD)
├── style.css           # Glassmorphism UI, адаптивность, темная кибер-фэнтези тема
├── app.js              # Главный контроллер, Telegram Haptic, игровой цикл, логика хода бота
├── canvas_renderer.js  # High-DPI Canvas рендерер (Retina, HUD здоровья/маны, веер карт, анимации)
├── particles.js        # Система спецэффектов (всплывающий урон/лечение, огонь, метеоры, тряска экрана)
├── audio.js            # Процедурный синтезатор звуков на Web Audio API (без внешних mp3)
├── engine.js           # Игровой движок дуэли (независим от DOM/Canvas)
├── game_rules.js       # Баланс, карты и константы
├── game_rules.json     # JSON-справочник карт
├── test_engine.js      # Набор модульных тестов движка
└── rules_summary.txt   # Сводка правил дуэли
```

## Особенности Canvas UI и TMA-клиента

1. **Telegram WebApp SDK интеграция:**
   - Автоматический `ready()` и `expand()` для полноэкранного режима на iOS и Android.
   - Адаптация под тему Telegram (темная/светлая палитра).
   - Тактильная отдача **HapticFeedback** (`impactOccurred('medium' / 'heavy')` при ударах и розыгрыше карт, `notificationOccurred('success')` при победе).
   - Подхват имени пользователя из Telegram профиля.

2. **Графика и анимации на Canvas:**
   - Поддержка Retina / High-DPI (`devicePixelRatio`) без размытия текста и иконок.
   - Динамический расчет веера карт в руке (автоматический скейлинг под ширину экрана).
   - Интерактивные состояния: подъем и свечение карты при наведении/выборе, драг-н-дроп на поле боя или розыгрыш в один тап.
   - Анимированные полоски здоровья с «призрачным» красным следом полученного урона.
   - Кристаллы маны с неоновым свечением.
   - Вылет и зависание разыгранной карты в центре поля перед срабатыванием эффекта.

3. **Спецэффекты и частицы (`particles.js`):**
   - Всплывающие цифры урона, чистого урона, лечения, прироста щита и отражения.
   - Огненные вспышки и осколочный взрыв метеорита.
   - Изумрудные искры лечения и токсичный дым яда.
   - Травматическая тряска экрана (Screen Shake) при мощных ударах.

4. **Процедурный звук (`audio.js`):**
   - Звуки сгенерированы в реальном времени через Web Audio API.
   - Мгновенный отклик без задержек и без необходимости скачивать аудиофайлы.
   - Кнопка отключения звука в верхнем HUD.

5. **Плавный ИИ соперника:**
   - Соперник (Вася / Бот) играет с естественными задержками между действиями (~700–900 мс), позволяя игроку видеть все анимации и ходы врага.

## Запуск локально

Для запуска локального сервера (любым статическим HTTP-сервером):

```bash
# Вариант с Node.js:
npx serve .

# Или через Python:
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000` в браузере или прокиньте через ngrok/localtunnel в `@BotFather` как URL для Telegram Mini App.
